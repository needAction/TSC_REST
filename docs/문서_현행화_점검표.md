# 서버 문서 현행화 점검표

기준일: **2026-10-26**. 현재 저장된 코드·설정·CSV와 문서의 설명을 대조했습니다. 문서·링크만 갱신하며 게임 코드·사용자 설정·CSV·프리팹·베이크·기존 빌드 결과는 변경하지 않습니다.

## 1. 현재 기능과 설정

- Join은 Start_UI의 탈출하기로 입장합니다. 이미 두 명을 확인하면 WaitingRoom_UI 생성을 생략하고, 양쪽 ready 이후 조작을 허용합니다.
- 에디터 `http://192.168.1.34:3001`, 개발 빌드 `http://192.168.1.34:3001`, 일반 빌드 `http://32.236.55.218:3000`가 현재 파일의 주소입니다. 실제 원격 접속 성공을 새로 확인한 것은 아닙니다.
- 게임 HTTP 본문은 프로토버프이며 서버가 정답·허가·해금을 소유합니다. 위치·경첩 회전·화면·소리는 클라이언트 표현입니다.
- 플레이 중 상태 조회는 5초, 대기·준비는 1초, 생존 전송은 3초, 서버 기본 만료는 10초입니다. 마지막 자기 정답 후 공동 완료 조회는 1초입니다.
- 마지막 방은 A 1013/퍼즐 5007, B 1014/퍼즐 5008의 BothSolved·Next=0입니다. 양쪽 정답 확인 후 문 개폐·통과 없이 영상으로 이어집니다.
- A/B 손 모델과 공통 대기·걷기 제어기, 생성 실패 입력 직접 해제, 구독 정리·반복 해제 보호가 연결되어 있습니다.
- 조명은 기존 앵커 → PREFAB, 역할별 프로브 베이크·복원입니다. ROOM_LIGHT_SPAWNTABLE은 현재 사용하지 않습니다. 사운드도 CSV 대신 GameFeedback 설정을 사용합니다.
- 영상 완료 뒤 Result_UI를 생성하고 재생 자원을 해제합니다. 탈출 시간은 인게임 진입부터 실제 영상 시작까지입니다. 확인 버튼은 종료이며 명시적 퇴장 완료 대기는 보장하지 않습니다.
- 서버는 메모리 세션 하나입니다. 영구 저장·신분 복구·다중 매칭·전체 원시 패킷 추적·오류 전용 파일 로거는 없습니다. 도커 로그 회전은 기본 10MB×3개이고 CPU·메모리 제한과 구분합니다.

## 2. 이번에 고친 문서 불일치

현재 주소와 예시 localhost를 구분하고 자동 입장 설명을 버튼 입장으로 고쳤습니다. 이미 구현된 문·다음 방·손·소리·프로브를 후속 또는 보류로 적은 부분을 바로잡았습니다. 초기 LED·R2A_LOCK 누락은 과거 사례로 표시했습니다.

상세 구조 문서의 미완성 코드 링크·목차·데이터 관계·컬럼 표·소스 색인을 채웠습니다. 클라이언트 상세 구조 원본은 클라이언트 Docs/ClientCodeArchitecture.md로 옮겼고 서버의 기존 파일은 위치 안내로 바꿨습니다. 과거 검사 날짜·수치는 현재 실행 결과로 다시 쓰지 않았습니다.

## 3. 이번 확인 결과

| 확인 | 결과와 범위 |
|---|---|
| 서버 빌드·전체 회귀 | **176개 통과·실패 0**. 이번에 실제 재실행 |
| 서버 CSV | **24개·오류 0·경고 15**, 활성 14개. 현재 서버 검증기 실행 |
| 클라이언트 CSV | **14개·오류 0·경고 0**. 현재 서버 공통 검증기로 해당 폴더를 검사한 결과이며 Unity 자원 검사가 아님 |
| 활성 표의 서버·클라 비교 | 문자열 행 기준 일치 14개, 차이 0개, 클라 누락 0개. 파일 수·BOM·줄바꿈 개수와 구분 |
| 유니티 실행·새 클라이언트 빌드·두 PC·음성·새 베이크·클라우드 재배포 | 이번 작업에서 수행하지 않음 |

기본 제한 환경에서는 로컬 HTTP 접속이 EACCES로 거부되어 서버 HTTP 검사가 실패했습니다. 제한 밖에서 같은 전체 검사를 다시 실행해 176개 통과를 확인했습니다. 처음 실패를 게임 규칙 오류로 기록하지 않습니다.

2026-10-23의 프로브 A/B 실행, 손 31개 검사, 프로브 수정 당시 실제 Stable 빌드와 이후 손 코드의 플레이어 참조 컴파일은 별도 시점의 과거 기록입니다. 그 빌드가 현재 소스를 모두 포함한다고 단정하지 않습니다.


### 클라이언트 원본 검사 프로젝트의 주의 사항

1. `Tools/CsvValidation.Tests/ConnectionConfigurationChecks.cs`는 editor 주소를 `http://127.0.0.1:3000`으로 고정 기대합니다. 현재 사용자 config는 `http://192.168.1.34:3001`이므로 그 단언과 맞지 않습니다. 문서 갱신을 위해 사용자 설정을 임의로 바꾸지 않았습니다.
2. `Tools/RoomClear.Tests/RoomClear.Tests.csproj`에는 현재 검증 코드가 사용하는 `ContentContract.cs`의 Compile 참조가 없습니다. 독립 실행에서 발생하는 참조 구성 문제와 Unity 게임의 런타임 오류는 다릅니다.
3. 과거 임시 사본·고정 코퍼스·실제 원본 실행의 통과 수를 섞지 않습니다. 329·78·48·41과 HTTP 24 등의 표는 해당 날짜의 검사 기록입니다. 이번 갱신에서 클라이언트 전체 회귀를 새로 실행한 것은 아닙니다.
