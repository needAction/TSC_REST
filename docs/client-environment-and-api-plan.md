# 환경별 접속과 현재 게임 API 연결 범위

> 문서 대조일: **2026-10-26**. 현재 코드·설정을 기준으로 설명을 점검했습니다. 본문의 과거 검사 수치·실행 기록은 해당 날짜의 결과입니다. [현재 상태·문서 검토 범위](문서_현행화_점검표.md)를 함께 확인합니다.

## 1. 접속 주소와 메뉴

클라이언트 원본은 `Assets/StreamingAssets/Configuration/connection.json`입니다. 에디터 `http://192.168.1.34:3001`, 개발 빌드 `http://192.168.1.34:3001`, 일반 빌드 `http://32.236.55.218:3000`가 현재 저장값입니다. 이번 검토에서 실제 네트워크 연결을 검사한 값은 아닙니다.

Join의 Start_UI에서 **탈출하기**를 눌러 입장합니다. autoConnect 값과 관계없이 새 메뉴는 버튼을 기다립니다. 한 명이면 WaitingRoom_UI, 두 명을 확인하면 Ingame 준비로 이동하며 양쪽 ready 이후 조작을 허용합니다. 로컬 A/B는 에디터 전용입니다.

## 2. 현재 연결된 기능

공통 데이터 스폰·A/B 손 모델·대기/걷기 애니메이션·이동/시점·좌클릭 Closeup·정답 UI·문 허가·경첩 개폐·누적 다음 방·양쪽 마지막 정답 후 영상/결과가 연결되어 있습니다. 조명은 기존 앵커를 통한 A/B 프로브 베이크·복원, 소리는 GameFeedback 직접 참조를 사용합니다.

초기 계획의 “문/정답/플레이어는 다음 구현” 표기는 현재 상태가 아닙니다. 새 퍼즐 알고리즘·모든 콘텐츠 품질 검증·온라인 전체 시나리오는 별도 범위입니다.

## 3. 통신과 권한

게임 API는 HTTP + `application/protobuf`, 참가 인증은 `x-participant-token`입니다. 서버는 정답·허가·해금, 클라이언트는 문 각도·위치·화면·소리를 소유합니다. 정상 오답과 요청 실패를 구분하고 온라인 실패를 로컬 정답 판정으로 바꾸지 않습니다.

조회는 대기/준비 1초·플레이 5초, 생존 확인은 3초이며 서버 기본 만료는 10초입니다. 마지막 정답 후 공동 완료 확인은 별도 1초 조회입니다. 서버 상태 확인 `/health`와 구분합니다.
